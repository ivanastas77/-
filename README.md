Программное средство для обработки текстовой информации с криптографической защитой
Описание проекта

Данный проект представляет собой программное приложение с графическим пользовательским интерфейсом для шифрования и расшифрования текстовой информации с использованием алгоритма PIKE. Приложение разработано в рамках производственной практики и внедрено в усовершенствованный бизнес-процесс обработки текстовых данных , обеспечивая повышенный уровень информационной безопасности, удобство использования и надёжность работы.

Основные возможности
- Ввод и редактирование текстовых данных через удобное многострочное поле.
- Шифрование и расшифрование текста с использованием алгоритма PIKE.
- Поддержка ввода пользовательского ключа шифрования (по умолчанию используется автоматический ключ).
- Автоматическая проверка корректности данных и ключа.
- Возможность сброса данных и возврата ключа к исходному значению.

- Python 3.x
- Алгоритм шифрования PIKE
